# Destroy Any Website

A browser-based 2D destruction sandbox built with vanilla HTML, CSS and JavaScript.

## Play locally
Open `index.html` in a modern browser. No build step, package manager, API key or backend is required.

## GitHub Pages
In repository settings, open **Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

Published URL: https://lordlolqdh.github.io/destroy-any-website/

## Controls
- **A / D** or **← / →**: move
- **W / Space / ↑**: jump
- **Mouse**: aim
- **Mouse click**: fire
- **R**: reset
- Touch controls are available on small screens.

## Gameplay
Enter a domain to generate a themed, destructible website facade. Break its components, defeat glitch enemies, collect score and advance through levels. The current prototype uses generated environments rather than loading and modifying third-party websites. Browsers isolate cross-origin pages, and this game never changes a real target website.

## Stack
- HTML5 Canvas
- Vanilla JavaScript
- Responsive CSS
- No external dependencies
